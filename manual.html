介護申請書 転記ツール　設定と使い方

アプリ：https://denkato0219-cell.github.io/kaigo-shinsei/　→ アプリを開く

📱 スマホ編💻 パソコン編✅ 共通ルール・困ったとき
このツールでできること：介護保険被保険者証の内容を読み取り、北九州市の「要介護認定・要支援認定等申請書」を、記入済みの状態で白紙のA4に枠ごと印刷します。
入力した内容は保存も送信もしません。ページを閉じると消えます。

📱 スマホ編

設定最初に1回だけ（iPhone）

  1. カメラの文字認識をオンにする
    設定 → カメラ →「検出されたテキストを表示」をオン
    設定 → 一般 → 言語と地域 →「テキスト認識表示」をオン
  2. ホーム画面にアイコンを置く（ここが大事）
    1. Safariでアプリのアドレスを開く
    2. 共有ボタン（□に↑）→「ホーム画面に追加」
    3. 「Webアプリとして開く」をオフにして「追加」
    オンのままだと印刷できません。画面の上に赤い注意が出たら、アイコンを削除して作り直してください。
    「Webアプリとして開く」の項目が出ない機種では、そのまま追加して、印刷するときだけSafariで開いてください。
  3. コピーした内容が他の機器に渡らないようにする（Mac・iPadを使っている人）
    設定 → 一般 → AirPlayと連携（またはHandoff）→「Handoff」をオフ
  4. プリンターをつなぐ
    AirPrint対応のプリンターなら、同じWi-Fiにつなぐだけで使えます。対応していない場合は、メーカーのアプリ（Canon PRINT／Epson Smart Panel／Brother Mobile Connect など）を入れてください。
  5. 事業所の情報を確認する
    アプリの②「提出代行者・申請者住所」に、名称・住所・電話が最初から入っています。番号と担当者を入れて「この端末に覚える」にチェックします。
  6. 試し刷りをする
    架空の名前で入力して印刷し、窓口の紙の申請書と重ねてずれを見ます。全体が少し縮むときは、③の「詳細設定」→「印刷倍率」を101〜103%に上げて合わせます（その端末に記憶されます）。

設定Androidの場合

  • 文字の読み取りは Googleレンズ を使います。
  • Chromeでアプリを開き、メニュー（︙）→「ホーム画面に追加」。
  • プリンターは、メーカーのプラグインか「Mopria Print Service」を入れます。

毎回使い方

  1. ホーム画面のアイコンからアプリを開き、①の「📷 カメラで証を読み取る（iPhone）」を押します。
  2. 枠をもう一度タップ → 出てきたメニューの「テキストをスキャン」（カメラのマーク）を押します。
  3. カメラが開くので被保険者証に向け、文字が黄色の枠で囲まれたら「挿入」。自動で②に入ります。
    うまくいかないとき・Androidの場合は、コピーして貼り付けます。
    iPhone：カメラアプリで証に向け、右下の［テキスト認識］→「すべてを選択」→「コピー」（シャッターは押さない）
    Android：Googleレンズ →「テキスト」→「すべて選択」→「コピー」
    → アプリの①の枠を長押しして「ペースト」
  4. ②を上から順に目で確認します。黄色の欄は自動で入った項目です。
    • フリガナ・個人番号は証に無いので手で入れます。
    • 主治医・医療保険などは分かる範囲で入れます。
  5. ③「🖨 印刷する」→ プリンターを選ぶ → 用紙A4・部数を確認 →「プリント」
    （Android：「プリンタを選択」でプリンターを選ぶ → 用紙A4 → 印刷ボタン）
  6. 印刷した紙に手書きする（下の「共通ルール」参照）。
  7. 後片付け：「入力をすべて消す」を2回押す → 何か別の文字をコピーして、クリップボードを上書きする。

💻 パソコン編

設定最初に1回だけ

  1. 開き方を決める（どちらか）
    ネットで開く（おすすめ）Chrome または Edge でアプリのアドレスを開き、お気に入り（ブックマーク）に登録します。いつも最新版が使えます。
    ファイルで開く「介護申請書転記.html」をデスクトップなどに置き、ダブルクリックで開きます。ネットにつながっていなくても入力・印刷できます。直したときはファイルの差し替えが必要です。
  2. 事業所の情報を確認する：スマホ編の5と同じです。
  3. 印刷の設定を確かめる（試し刷り）：下の「印刷画面の設定」のとおりにして1枚印刷し、紙の申請書と重ねてずれを見ます。

毎回使い方

  1. アプリを開きます。
  2. 被保険者証の内容を入れます（どれか）。
    • 手で入力：②に直接入れます。いちばん確実です。
    • 写真から読み取る：①「写真を選ぶ」で証の写真を選び、読みたい欄を囲んで「読み取り開始」。精度は低めです。氏名・生年月日は手で直してください。
    スマホで読み取った文字を、LINEやメールでパソコンに送るのはやめてください（個人情報が外に出ます）。スマホで読み取ったときは、スマホからそのまま印刷してください。
  3. ②を上から順に目で確認します。
  4. ③「🖨 印刷する／PDFに保存」を押して、下の設定で印刷します。
  5. 印刷した紙に手書きします。
  6. 後片付け：「入力をすべて消す」を2回押して、ブラウザのタブを閉じます。

印刷画面の設定（Chrome・Edge）

送信先／プリンター使うプリンター
部数窓口で確認した枚数
用紙サイズA4
余白なし
倍率（拡大縮小）100（「ページに合わせる」にしない）
ヘッダーとフッターオフ（チェックを外す）

「余白」「倍率」「ヘッダーとフッター」は「詳細設定」を開くと出てきます。一度設定すれば、次からは同じ設定になることが多いです。

PDFで残す場合は、送信先を「PDFに保存」にします。保存したPDFは個人情報なので、事業所のルールに従って保管・削除してください。

✅ 共通ルール

印刷後に手書きするところ

  • 同意する項目の ☑（「介護情報の提供」「とびうめ＠きたきゅう」）
  • 被保険者氏名（必須）の署名
  • 代筆者氏名・続柄（代筆した場合）
  • 印字されていない空欄で、必要なところ

個人情報を守るために

しないこと理由かわりに
メモ帳で証をスキャンする証の画像がメモに残り、iCloudにも保存されるカメラの［テキスト認識］を使う
シャッターを押して撮る写真アプリに残る撮ってしまったら削除し、「最近削除した項目」からも消す
文字をLINE・メールで送る端末の外に出る読み取った端末から直接印刷する
PDFを保存したまま放置する端末やクラウドに残る印刷だけにする。保存したら使い終わりに削除

スマホ・パソコンとも、パスコード（パスワード）と自動ロックを必ず設定してください。

大事なこと

  • 読み取りは完璧ではありません。印刷前に必ず目で確認してください。
  • 申請書の様式が変わったら使えなくなります。窓口で新しい様式を渡されたら、管理者に知らせてください。

🔧 困ったとき

こんなときこうする
印刷ボタンを押しても何も出ない（iPhone）ホーム画面のアイコンが「Webアプリ」になっています。スマホ編の設定2のとおり作り直すか、Safariで開いて印刷します。
プリンターが出てこない同じWi-Fiにつながっているか確認します。AirPrint非対応なら「PDFに保存」してメーカーのアプリで印刷します。
印刷が少し小さい／ずれる倍率100%・余白なしを確認します。それでもずれるときは、③「詳細設定」の「印刷倍率」「全体ずらし」で合わせます。
2ページになる／ヘッダーに日付やアドレスが出るパソコンの印刷画面で、余白「なし」、ヘッダーとフッター「オフ」にします。
貼り付けても項目が入らない「貼り付けた文字から入力」を押します。入らない項目は手で入れます。
画面が古いままブラウザで開いて、読み込み直します（スマホは画面を下に引っぱる）。
事業所の住所などを1回だけ変えたい②でその回だけ書き換えます。「入力をすべて消す」で元に戻ります。
